# Письма Империй - modern web interface

Интерфейс переписан со статического HTML/CSS/JS на Vite + React + TypeScript.
Визуальная база сохранена: политическая SVG-карта, панели державы, чат, приказы, хроника, письма и дипломатия.

## Стек

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Motion
- lucide-react
- Playwright smoke check

## Команды

```bash
npm install
npm run dev
npm run build
npm run smoke
```

Dev-сервер по умолчанию открывается на `http://127.0.0.1:5173/`.

## Структура

- `src/App.tsx` - основной React-интерфейс и интерактивное состояние.
- `src/assets/world-map.svg` - перенесенная SVG-карта мира из старого `index.html`.
- `src/styles.css` - Tailwind entrypoint, импорт сохраненных базовых стилей и новые правки.
- `scripts/smoke.mjs` - браузерная проверка карты, zoom, tooltip, чата и приказов.
- `docs/AI_ARBITRATION_DECISION_MODEL.md` - заметка о будущем Qwen-арбитраже: невозможные действия, рискованные решения и негативные последствия.
- `legacy-static/` - снимок исходной статической версии до переписывания.
- `Письма Империй.docx` - продуктовый план v2; серверный AI/DB слой описан там, но не входит в этот перенос.

## Проверки

Последний проход:

- `npm run build` - pass
- `npm run smoke` - pass

Smoke проверяет загрузку приложения, наличие 176 стран на карте, переключение режима карты, скрытие маршрутов, zoom, tooltip и выбор России, отправку сообщения в чат, отмену приказа и отсутствие ошибок в консоли.

## Заметки

Desktop-кабинет является приоритетом этого переноса. Mobile-версия не ломает страницу и не дает горизонтальный overflow, но полноценную мобильную UX-компоновку лучше делать отдельным этапом.
