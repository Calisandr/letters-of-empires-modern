# Письма Империй — веб-интерфейс

Статический сайт, собранный с нуля по предоставленному дизайну. Изображение-референс не вставлено в проект: карта сделана как SVG-вектор, панели и элементы интерфейса — HTML/CSS.

## Как открыть

Откройте `index.html` в браузере. Все стили и скрипты лежат локально в папках `css/` и `js/`, интернет не нужен.

## Что внутри

- `index.html` — разметка интерфейса и SVG-карта мира.
- `css/styles.css` — темная имперская стилизация, панели, карта, адаптив.
- `js/app.js` — переключение карты, зум, тултипы стран, чат, таймер хода.

## Аватарки

Места под аватарки оставлены пустыми: `.profile-avatar` и `.ruler-avatar`. В них можно позже вставить свои изображения.
